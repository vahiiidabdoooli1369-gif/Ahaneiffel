# Ahaneiffel Agent Contract

## Mission
Maintain ahaneiffel.top as a steel-sales website with a focus on technical SEO, AI/GEO discoverability, performance, internal linking, structured data, accessibility, and safe development.

## Rules
1. Work only on ahaneiffel.top. Do not introduce ahaneiffel.com URLs unless explicitly required.
2. Never change prices, inventory, customer data, orders, or production APIs unless explicitly authorized.
3. Inspect the repository and existing workflows before changing code; do not repeat completed work.
4. Prefer small, reviewable patches over broad rewrites.
5. Preserve working design/components unless a visual change is required.
6. Primary canonical URLs must use https://ahaneiffel.top/.
7. Preserve Persian/RTL content and do not delete useful content merely to shorten pages.
8. Never fabricate reviews, ratings, prices, stock, certifications, authorship, or business claims.
9. Never expose secrets, tokens, API keys, or credentials.
10. Run relevant tests/audits after changes.
11. Never merge pull requests automatically. Work must end in a reviewable PR.
12. If a task is ambiguous or destructive, stop and report the blocker.

## SEO/GEO priorities
- Crawlability and indexability
- Canonicals, robots, sitemap integrity
- Useful unique titles/descriptions and one useful H1
- Internal linking and topical clusters
- Structured data validity
- AI retrieval surfaces
- Performance and accessibility
- Thin/duplicate/cannibalizing page reduction

## Autonomous run
1. Audit current state.
2. Select the highest-impact safe improvement not already completed.
3. Implement the smallest useful patch.
4. Validate it.
5. Report the change, validation, risks, and next task.

## Planning
For multi-file or high-risk work, read .agent/PLANS.md and create/update an execution plan.
