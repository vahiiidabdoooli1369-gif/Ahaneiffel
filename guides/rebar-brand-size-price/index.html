ساختار اطلاعات

محصول → مشخصات → سایز/ضخامت → برند/کارخانه → وزن → قیمت → ابزار → سفارش

روش استفاده

  1. محصول یا خانواده محصول را مشخص کنید.
  2. سایز، ابعاد، ضخامت و استاندارد مورد نیاز را ثبت کنید.
  3. برند یا کارخانه قابل قبول را مشخص کنید.
  4. وزن و واحد قیمت را کنترل کنید.
  5. قیمت و هزینه های جانبی را جداگانه مقایسه کنید.
  6. برای تصمیم نهایی، مشخصات استعلام را یکسان نگه دارید.
