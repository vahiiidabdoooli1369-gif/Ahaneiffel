# SEO / AI crawler guidance

## Purpose
This file documents the crawl/indexing priorities for Ahaneiffel. It is not a replacement for robots.txt, sitemap.xml, canonical tags, or Search Console.

## Priority sections
- /prices/ — commercial price-intent hub
- /products/ — product taxonomy
- /buy-iron/ — commercial purchase intent
- /reference/ — topical authority hub
- /guides/ — supporting informational content
- /tools/ — useful decision and calculation tools
- /services/ — project supply and delivery information
- /brands/ — manufacturer/brand entities
- /local/tehran/ — local commercial intent

## Content principles
1. Keep one clear search intent per URL.
2. Use self-referencing canonical URLs on indexable pages.
3. Link important commercial pages from relevant hubs and supporting guides.
4. Avoid creating near-duplicate city, size, or keyword pages without unique user value.
5. Keep product facts, dimensions, weights, standards, manufacturers, price methodology, delivery conditions, and contact information explicit and machine-readable.
6. Do not fabricate live prices. Where a live value is unavailable, clearly label it as requiring confirmation.
7. Keep structured data consistent with visible page content.

## Crawl priority
Homepage → commercial hubs → product pages → buying guides → tools → supporting/local pages.

## Maintenance
Run the site's SEO validation workflow after changes and review Search Console indexing reports before expanding the URL footprint.
