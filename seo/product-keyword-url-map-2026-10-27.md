# نقشه اجرایی کلیدواژه به URL آهن ایفل
تاریخ: ۱۴۰۵/۰۸/۰۵ | دامنه هدف: https://ahaneiffel.top
این نقشه مکمل PR #101 است. مسیرها از درخت فایل مخزن استخراج شده‌اند؛ وجود فایل در GitHub اثبات انتشار زنده نیست. پیش از تغییر هر صفحه، HTTP و canonical زنده را بررسی کنید. حجم جست‌وجو/رتبه این عبارات هنوز با GSC یا Keyword Planner تأیید نشده است.

## قانون تخصیص برای جلوگیری از رقابت صفحات
- «قیمت روز + محصول» ← فقط صفحه قیمت همان محصول.
- «خرید/مشخصات/کاربرد» ← صفحه مادر محصول.
- «سایز یا ابعاد دقیق» ← صفحه سایز موجود؛ اگر وجود ندارد فعلاً بخش صفحه مادر، نه ساخت URL تازه.
- «وزن/جدول وزن» ← یک راهنمای وزن اصلی.
- «برند + قیمت» ← صفحه قیمت برند، فقط در صورت وجود عرضه و داده تأییدشده.
- صفحه راهنما/مقایسه نباید برای عبارت «قیمت روز» با صفحه قیمت رقابت کند.
- در هر صفحه یک عبارت اصلی و چند عبارت فرعی هم‌نیت؛ پیش از تغییر Title/H1، داده GSC را بررسی کنید.

## صفحات مرکزی
- صفحه اصلی /: برند و معرفی؛ نه مالک قیمت تمام سایزها.
- /products/: مسیر ناوبری به گروه محصولات.
- /prices/: مرکز قیمت عمومی و لینک به قیمت محصول.
- /iron-products/comparison/ و /reference/steel-product-comparison/: نیت مقایسه، نه قیمت روز.
- /reference/ai-retrieval-map/: مسیر مرجع‌دهی AI؛ URL اصلی و canonical زنده باید بررسی شود.

## ۱۰ اقدام اجرایی بعدی
1. بررسی HTTP، canonical و indexability زنده تمام URLهای بالا.
2. دریافت GSC query × page برای ۹۰ روز و ۱۲ ماه.
3. ثبت URL دارای بیشترین impression برای هر عبارت در فایل مستقل.
4. شناسایی عبارت‌هایی که چند URL برایشان نمایش گرفته‌اند.
5. انتخاب یک URL مالک برای هر خوشه بر اساس intent و داده.
6. تغییر Title/H1 فقط در صفحات دارای ناهماهنگی اثبات‌شده.
7. افزودن لینک دوطرفه مادر ↔ سایزهای موجود.
8. لینک از راهنماها به صفحه قیمت/محصول مرتبط، بدون تکرار انبوه.
9. تست schema، sitemap، canonical و نمایش موبایل بعد از انتشار.
10. بازخوانی URL زنده و مقایسه clicks، impressions، CTR، position و درخواست قیمت بعد از ۲۸ روز.

## کارهایی که نباید بدون داده انجام شوند
ساخت صفحه برای هر مترادف؛ تغییر URL/canonical انبوه؛ جعل حجم جست‌وجو؛ تغییر نرخ یا تاریخ قیمت بدون تأیید فروش؛ درج امتیاز/نظر/موجودی ساختگی؛ فرض انتشار زنده فقط از روی وجود فایل در GitHub.
