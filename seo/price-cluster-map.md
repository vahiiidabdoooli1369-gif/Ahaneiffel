# نقشه اتصال خوشه‌های قیمت و محصول

این فایل مرجع داخلی معماری لینک‌سازی سئو سایت آهن ایفل است.

## قوانین
- صفحات قیمت باید به هاب محصول مرتبط لینک بدهند.
- صفحات قیمت سایز باید به محصول همان سایز و صفحه قیمت مادر لینک بدهند.
- صفحات برند باید به خوشه قیمت برند و محصولات مرتبط لینک بدهند.
- ابزارها فقط وقتی لینک شوند که به تصمیم خرید همان خوشه کمک کنند.
- قیمت زنده یا Offer ساختگی ایجاد نشود.
- Canonical همیشه روی دامنه اصلی `https://ahaneiffel.top/` باشد.
- صفحات تکراری یا legacy باید noindex/canonical/redirect مناسب داشته باشند.

## خوشه‌های اصلی

### میلگرد
قیمت امروز → قیمت برند ذوب آهن → قیمت سایز → محصول سایز → جدول وزن → ابزار محاسبه وزن/سفارش → راهنمای خرید

### تیرآهن
قیمت امروز → قیمت ذوب آهن → قیمت سایز → محصول سایز → جدول وزن → ابزار مقایسه پیشنهاد → راهنمای خرید

### پروفیل
قیمت امروز → هاب پروفیل → صفحات سایز/ضخامت → ابزار انتخاب و برش → راهنمای قیمت و خرید

### ورق
قیمت امروز → ورق سیاه/مبارکه → صفحات محصول → ابزار محاسبه وزن → راهنمای خرید

### نبشی
قیمت امروز → هاب نبشی → صفحات سایز → جدول وزن/انتخاب سایز → راهنمای خرید

## معیار موفقیت
هر صفحه تجاری مهم باید حداقل یک مسیر داخلی واضح به صفحه بالادستی و یک مسیر به صفحه تصمیم خرید پایین‌دستی داشته باشد. این سند فقط نقشه معماری است و جایگزین بررسی واقعی لینک‌ها نیست.
